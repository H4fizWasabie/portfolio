Why it exists

Work away from a desk doesn't wait for signal, so what's on the phone has to work at zero bars. MAP keeps five daily tools — tasks, calendar, documents, scan-to-PDF and a local music player — behind one calm Home/Today view, all of it on-device. The name is My Awesome App and it wears it.

What it handles

  • Home/Today — one calm surface: what's next, what's due, what's playing.
  • Tasks — the day's list, offline by default.
  • Calendar — the month at a glance.
  • Documents — a local document shelf with a viewer.
  • Scan to PDF — paper to PDF, from the field.
  • Music — a local player; the files are yours, on the device.

Under the hood

  • Kotlin, local-first by construction. No account, no backend, no analytics, no cloud sync — nothing in the app phones anywhere, because there is nothing to phone to.
  • Shipped as a sideload APK. GitHub Releases with published sha256 checksums. Debug-signed, and the README warns you Android will complain about installing it — expected for a personal APK outside the Play Store.
  • The release queue is a file. AGENTS.md, CONTEXT.md and CHANGELOG.md keep the product vocabulary and release queue in the repo; the app builds on Android SDK 36.
  • Version numbers mean something. v0.1.0 → v0.1.1 in five days, and the APK came out 0.6 MB lighter.

The honest edges

  • The weight. 48 MB is not a hello-world — five real modules live in one APK. It got 0.6 MB lighter between releases; nobody is pretending it is a 2 MB note app.
  • Sideloaded, not shelved. No store listing. Installing it means trusting the GitHub release and checking the sha256 yourself — the checksum is published next to the binary for exactly that reason.
  • The audience is one. A personal app at v0.1.x, built because its user wanted it. No download counts to brag about.
  • Data stays — including the risk. No account, no cloud sync: no sync magic and no safety net behind the device.
  • The tests are named, not implied. The repo carries 4 test files beside the Kotlin sources — that is the whole suite, stated plainly.
  • No roadmap claims. Everything above is either in the APK or in the repo.
