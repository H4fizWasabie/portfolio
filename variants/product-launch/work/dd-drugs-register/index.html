DD Drugs Register

Make daily counts accountable.

A hospital dangerous-drugs register that compares physical and system counts while preserving the record.

  • Go
  • SQLite
  • Audited corrections

The workflow

Workflow outline only; no clinical records shown. This is an authored workflow outline, not an app screenshot.

  1. Enter the daily physical count
  2. Compare with the system count
  3. Identify any discrepancy
  4. Record a correction with a reason

Why it exists

A daily count needs a clear owner, an explicit discrepancy and a correction history that does not erase the original entry.

What I built

I built a multi-user daily register with physical-versus-system counts, discrepancy flags, audited corrections and CSV export. Original entries remain in the ledger when a correction is made.

How it is built

Go and SQLite provide a compact application and a persistent register. Corrections reference the original entry instead of replacing it. Multi-user login makes entries attributable.

What this page does not claim

Drug names, storage locations, quantities and staff records stay private. This page shows a workflow outline, not the hospital interface or a compliance certification. The source repository is private.
